# B창고 CCTV 녹화서버 구축 — 작업지시서

> 이 PC에서 실행 중인 Claude Code에게. 이 문서를 먼저 끝까지 읽고 시작할 것.
> 사용자는 리플래시 대표(비전문가)다. **친절하게, 한 번에 한 단계씩** 안내하고,
> 네가 직접 할 수 있는 일은 전부 네가 해라. 사용자에게는 휴대폰 Tapo 앱 조작만 부탁해라.

---

## 0. 목표

B창고 Tapo 카메라 7대를 이 PC가 24시간 녹화하고, Tailscale로 A창고 관제화면에 합류시킨다.
A창고(가좌동2층)는 이미 5대가 돌아가고 있고, B는 **녹화 + Tailscale 연결만** 담당한다.
웹 콘솔은 A PC가 호스팅하므로 B는 콘솔을 만들지 않는다. 파이썬도 필요 없다.

같은 폴더의 `0_먼저읽어주세요_클로드에게.md`, `1_설계전체_설명.md` 에 A창고 구축 이력이 있다.
**이 문서가 우선한다.** 두 문서와 충돌하면 이 문서를 따라라.

## 2. 용량 계산 (이미 계산됨)

A창고 실측이 5대에 하루 40GB → 대당 8GB. 7대면 하루 56GB, 외부 카메라는 움직임이 많아
실제 60GB 안팎. D드라이브 931GB에서 여유 80GB를 남기면 **약 2주 보존**.

그래서 이렇게 간다:
- `recordDeleteAfter: 720h` — 30일을 **상한**으로만 걸어둔다
- **용량지킴이**가 1시간마다 D드라이브를 검사해서 여유 80GB 미만이면 오래된 파일부터 삭제

날짜를 미리 못 박지 않고 디스크에 들어가는 만큼 최대한 오래 보관하는 방식이다.
`B_2_서버설치_D드라이브.ps1` 이 둘 다 자동으로 설정한다. **직접 계산해서 바꾸지 마라.**

## 3. 작업 순서

### STEP 1 — 카메라 찾기

두 ps1 파일은 브라우저로 받은 것이라 윈도우가 차단해 둔 상태다. 먼저 풀어야 한다.

```powershell
Get-ChildItem C:\cctv-setup\*.ps1 | Unblock-File
powershell -ExecutionPolicy Bypass -File C:\cctv-setup\B_1_카메라찾기.ps1
```

**554 포트가 열린 IP가 몇 개 나왔는지 그대로 보고하고 멈춰라.**

| 결과 | 뜻 |
|---|---|
| 7대 | 전부 준비됨 → STEP 2로 |
| 1대 | `192.168.0.107` 만 설정됨 → 나머지 6대 Tapo 앱 작업 필요 |
| 2~6대 | 일부만 설정됨 → 빠진 것만 마저 작업 필요 |

7대가 아니면 사용자에게 이렇게 안내해라 — 각 카메라마다
**Tapo 앱 → 카메라 → 톱니(설정) → 고급 설정 → 카메라 계정**에서
`Reflashcam` / `[카메라비밀번호]` 생성 + **"활성" 스위치 ON** + **Tapo Care 해제**.
끝나면 카메라 전원을 뽑았다 꽂고 2분 뒤 STEP 1을 다시 실행.

### STEP 2 — 이름 ↔ IP 대조

찾은 IP 목록을 사용자에게 보여주고, Tapo 앱 각 카메라의 **설정 → 기기 정보 → IP 주소**와
대조해서 이름을 받아라. 아래 표를 채운 뒤 다음으로 넘어간다.

| 번호 | 이름 | IP | path |
|---|---|---|---|
| B-01 | ? | ? | b01 |
| … | | | |

`192.168.0.107` = `B창고 외부1` 은 이미 확정.

### STEP 3 — 서버 설치 (사용자 확인 후)

**관리자 권한 PowerShell**이 필요하다. 사용자에게 시작버튼 우클릭 →
"Windows PowerShell(관리자)"로 열어달라고 하고, 거기서 실행하게 해라.

```powershell
powershell -ExecutionPolicy Bypass -File C:\cctv-setup\B_2_서버설치_D드라이브.ps1
```

MediaMTX 다운로드, Tailscale 설치·로그인, 절전 해제, 방화벽, 감시 스케줄,
용량지킴이 등록, `mediamtx.yml` 뼈대 생성까지 전부 이 스크립트가 한다.

중간에 브라우저가 열리면 사용자에게 **`brown.rigoon@gmail.com` 구글 계정**으로
로그인하라고 안내해라. A창고와 같은 계정이어야 한 망으로 묶인다.

끝나면 바탕화면에 `B창고_설치결과.txt` 가 생기고 **B PC의 Tailscale IP**가 찍힌다.

### STEP 4 — mediamtx.yml에 카메라 등록

`C:\cctv\mediamtx\mediamtx.yml` 의 `paths:` 아래를 채운다. 카메라 대수만큼 반복.

```yaml
paths:
  b01:
    source: rtsp://Reflashcam:[카메라비밀번호]@192.168.0.xxx:554/stream1
    record: yes
  b01sub:
    source: rtsp://Reflashcam:[카메라비밀번호]@192.168.0.xxx:554/stream2
    sourceOnDemand: yes
```

**규칙:**
- `bNN` = 녹화용 고화질(stream1), `record: yes`
- `bNNsub` = 라이브 그리드용 저화질(stream2), **반드시 `sourceOnDemand: yes`**
- `webrtcAdditionalHosts` 에 STEP 3에서 얻은 Tailscale IP를 기입 (설치 스크립트가 이미 넣었으면 확인만)
- `pathDefaults` 는 손대지 마라 (`rtspTransport: tcp`, 녹화경로, 보존 설정이 이미 들어 있다)

> `sourceOnDemand: yes` 가 중요한 이유: 카메라 7대가 전부 2.4GHz 와이파이 한 대에 물려 있다.
> sub 스트림까지 24시간 당기면 대역폭이 모자라 녹화가 조각난다. 볼 때만 당기게 한다.

저장 후 재시작:
```powershell
Get-Process mediamtx -ErrorAction SilentlyContinue | Stop-Process -Force
Start-Process C:\cctv\mediamtx\mediamtx.exe -WorkingDirectory C:\cctv\mediamtx -WindowStyle Hidden
```

### STEP 5 — 검증

```powershell
Invoke-RestMethod http://127.0.0.1:9997/v3/paths/list | % items | ? ready | select name
```

카메라 7대면 `b01`~`b07` + `b01sub`~`b07sub` = **14개**가 나와야 한다.
(`sourceOnDemand` 인 sub는 접속 전까지 안 뜰 수 있다. `bNN` 7개가 전부 ready면 정상)

5분쯤 뒤 녹화 파일이 쌓이는지 확인:
```powershell
Get-ChildItem D:\cctv\recordings -Recurse -File | Measure-Object -Property Length -Sum
```

### STEP 6 — 최종 보고

작업이 끝나면 아래를 정리해서 사용자에게 출력해라. 사용자가 이걸 A창고 쪽에 전달한다.

- 카메라 목록:
  B-01 / (이름) / b01
  B-02 / (이름) / b02

## 4. 절대 하지 말 것

1. **공유기 리셋 버튼을 누르지 마라.** AP모드 전환도 불필요하다 — 이미 같은 망이다.
2. **카메라 펌웨어를 업데이트하지 마라.** 앱에 빨간 점이 떠 있어도 무시. Tapo 펌웨어가 RTSP를 깬 전례가 많다. 전체 구축이 끝난 뒤 1대만 시험한다.
3. **녹화나 로그를 C드라이브에 두지 마라.** C는 여유가 30GB뿐이다.
4. **새 스크립트를 임의로 만들지 마라.** `B_1`, `B_2` 를 쓴다. 고칠 곳이 있으면 먼저 사용자에게 알려라.
5. **사용자 확인 없이 설치를 진행하지 마라.** STEP 1 결과를 보고한 뒤 승인받고 STEP 3으로 간다.
6. **카메라 비밀번호를 반복 시도하지 마라.** 여러 번 틀리면 카메라가 보호잠금에 걸린다.

---

## 5. A창고에서 실제로 겪은 함정

1. 카메라 계정은 **생성 + "활성" 스위치 ON** 둘 다 해야 한다. 계정만 만들고 스위치가 꺼져 있으면 연결 안 됨.
2. 비밀번호에 특수문자(`$`, `@` 등) 금지.
3. 비번 연타로 보호잠금 → 카메라 전원 뽑았다 꽂으면 풀림.
4. **Tapo Care는 무료체험만 켜져 있어도 PC 녹화가 차단된다.**
5. 와이파이 순간 끊김으로 녹화가 조각날 수 있음 → `rtspTransport: tcp` 필수 (이미 설정됨).
6. 카메라 IP는 DHCP라 바뀔 수 있다. 나중에 공유기에서 고정 할당하는 게 좋다.
