### 통합화면 쓰는 법

폴더째 바탕화면에 두고 **`리플래시 CCTV 보기.vbs`** 더블클릭 → 브라우저에 12대가 뜹니다.
창은 뜨지 않습니다. 끄려면 `CCTV 끄기.vbs`. Tailscale이 켜져 있어야 합니다.

> `console.html` 을 그냥 더블클릭하면 **영상이 안 나옵니다.** `file://` 로 열린 페이지는
> 브라우저가 외부 서버 접속을 막기 때문입니다. 반드시 `.vbs` 로 실행하세요.

## ⚠️ 주의

1. **`B_2_서버설치_D드라이브.ps1` 을 다시 실행하지 마세요.**
   MediaMTX zip에 기본 `mediamtx.yml` 이 들어 있어, 재실행하면 현재 설정을 기본값으로 덮어씁니다.
   카메라가 전부 사라지고 녹화가 멈추는데 화면에는 "설치 완료"로 표시됩니다.

2. **설정 파일은 항상 전체를 교체하세요.** MediaMTX는 설정 파일을 하나만 읽고 `include` 가 없습니다.
   `paths:` 부분만 덧붙이면 키가 중복되어 서버가 시작되지 않습니다.

3. **저장 인코딩은 UTF-8 (BOM 없음).** BOM이 붙으면 파싱 에러로 기동에 실패합니다.

4. **카메라 펌웨어를 업데이트하지 마세요.** Tapo 펌웨어가 RTSP를 깬 전례가 많습니다.

5. **이 폴더의 파일에는 카메라 비밀번호가 평문으로 들어 있습니다.** 저장소를 비공개로 유지하세요.
