========================================
  리플래시 CCTV 통합화면 (A창고 + B창고)
========================================

[ 여는 방법 ]

  "리플래시 CCTV 보기.vbs"  <- 이것을 더블클릭하세요.

  아무 창도 뜨지 않고, 잠시 후 브라우저에 카메라 12대가 나옵니다.


[ 끄는 방법 ]

  브라우저 탭만 닫으면 화면은 사라집니다.
  완전히 끄고 싶으면 "CCTV 끄기.vbs" 를 더블클릭하세요.

  ※ 컴퓨터를 껐다 켜면 자동으로 꺼집니다. 굳이 끄지 않아도 됩니다.
  ※ 여러 번 더블클릭해도 중복 실행되지 않습니다.


[ 바탕화면에 아이콘으로 두기 ]

  1. "리플래시 CCTV 보기.vbs" 우클릭 -> [바로 가기 만들기]
  2. 만들어진 바로 가기를 바탕화면으로 옮기기
  3. (선택) 바로 가기 우클릭 -> [속성] -> [아이콘 변경] 에서
     원하는 그림 고르기
  4. (선택) 우클릭 -> [작업 표시줄에 고정]


[ 반드시 지킬 것 ]

  이 폴더 안의 파일들은 항상 같이 있어야 합니다.
    - 리플래시 CCTV 보기.vbs   (실행)
    - CCTV 끄기.vbs            (종료)
    - _server.ps1              (화면을 띄워주는 부분)
    - console.html             (화면 내용)
  폴더째로 옮기는 건 괜찮습니다. 파일 하나만 빼내면 안 됩니다.

[ 화면 사용법 ]

  마우스 휠      = 그 지점 확대

  더블클릭       = 그 카메라 타임점프 재생 (지난 영상 보기)
  오른쪽 위 [⛶]  = 고화질로 크게 보기


[ 안 나올 때 ]

  4. 그래도 안 되면 브라우저에서 F12 를 누르고
     "Console" 탭 화면을 캡처해서 알려주세요
